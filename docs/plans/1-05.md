## Design Palette Detail Page:
Palette Detail Page
On the existing palette page change the palette list card: remove the remove button which exists
now, and remove the copy hex problem From the Palette List screen (which displays all palettes
as cards), when the user taps on a palette card, they are navigated to a Palette Detail page.

On this page, the user can:

1. View Palette Information

1. Palette name
1. Tags
1. Description


2. View Colors in the Palette

Colors are displayed in a full-width vertical list.
Each color appears as a color card: color preview, name and hex, also RGB value HSL value.
Each color card includes a “View more” label or indicator.
Tapping anywhere on the color card triggers the same “View more” action
(no separate button required).

3. Edit Palette (Edit Mode)

An Edit button is available on the page. When enabled, the user can:
- Edit the palette name
- Edit tags
- Edit the description
- Reorder colors via drag-and-drop
- Delete colors from the palette
